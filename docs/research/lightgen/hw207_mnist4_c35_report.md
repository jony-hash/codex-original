### 核心问题答复

| 问题 | 结论及证据 |
|---|---|
| C3.3 相位能否直接迁移？ | **不能据现有结果认定可直接迁移。** C3.4 中同一历史 2,000 行上，C3.3 固定相位在理想 Model A 为 95.80%，换到估算 Model B（D=2 mm）为 48.30%。C3.5 再把冻结相位通过假设名义加工算子后，P3 子集为 33.8%（n=1,000）；这与 C3.4 的 48.30% 使用不同数值条件/子集，不能当作配对差。 |
| 是否必须重新训练？ | 几何适配训练在 C3.4 的另一留出集达到 95.75%，C3.5 加工感知高度在复用开发验证集达到 95.35%；**缺少冻结与重训在同一未参与选择样本上的配对结果**，因此不能声称重训带来可泛化的因果提升，也不据此宣布硬件上必须重训。对当前假设几何，重新优化是可行候选。 |
| 是否是真正光学分类？ | 没有训练数字分类头；判决由四个固定 CMOS ROI 积分和电子 `argmax` 完成。光学场负责形成类别相关强度分布，但 CMOS 后的求和与比较是电子步骤，故不是全光端到端判决。 |
| 是否发生能量塌缩？ | C3.5 P2 名义加工基线的全 CMOS 能量均值为 7,462.42 µm²、效率 10.685%（P10 8.156%），且 1,000 张样本没有全零 ROI 判决；仍只有约 10.7% 的输入面归一化能量计入完整 CMOS。由于传播几何和数值条件与 C3.3 `dz=0` 不同，不能据此判定其能量效率优于 C3.3。P1 加工基线能量较高（23,651.11 µm²、33.354%），ROI Accuracy 却只有 37.9%。总能量不能替代类别路由质量。 |
| 是否适合双光子打印？ | 只能说**参数化几何可导出且网格基本拓扑检查通过**。P2 STL 回读高度最大误差约 `5.01×10⁻⁶ µm`；Δn=0.5/0.6 假设下 round-trip Accuracy 为 95.4%/90.4%，均值 CMOS 能量为 7,332.10/7,823.84 µm²，均值效率为 10.61%/11.37%。通用三角面自交检测未运行，实际材料和打印工艺未知，不能称为加工就绪。 |
| 是否能进入实物验证？ | **目前不能按本报告放行。** DMD 收光方向、输入/输出 Relay 实测几何与倍率、LightGen 实际复透射、CMOS 坐标、532 nm 材料 Δn，以及打印机横向响应/最小特征/高度误差均未闭合。 |

## 科学认识

本轮发现的关键工程问题是旧 P3 的单因素场景没有固定其他名义加工项：P2 的部分 Δn 数值实际走了高度映射而未应用完整 PSF、最小特征与量化处理，不能解释为打印鲁棒性。修正后，名义算子固定为 Δn=0.5、PSF σ=0.8 px、最小特征半径 1 px、64 级高度、零噪声、零边缘偏置；Δn、PSF、最小特征和噪声各自单独变化，组合不利条件独立列出。

| P2 加工感知候选场景 | Accuracy | 平均效率 | 解读 |
|---|---:|---:|---|
| 名义算子（n=1,000） | 94.9% | 10.69% | 同一 C3.4 validation 子集，非独立人口。 |
| Δn=0.6 | 90.4% | 11.44% | 对这两个折射率假设有一定容忍度；材料 Δn 未测。 |
| 高度噪声 20 nm、5 个种子 | 94.7–95.2% | 约 10.5–10.6% | 仅对代码设定的噪声模型和种子范围。 |
| PSF σ=0 / 0.4 / 1.2 px | 50.0% / 56.4% / 85.1% | 30.40% / 27.76% / 16.85% | 对横向模糊假设显著敏感；名义 σ=0.8 px 为 94.9%。 |
| 最小特征半径 0 / 2 px | 93.0% / 58.7% | 8.00% / 29.85% | 对最小特征处理显著敏感；名义半径 1 px 为 94.9%。 |
| 组合不利场景 | 45.7–65.1% | 依场景而异 | 不能据名义表现宣称联合加工偏差下稳健。 |

P2 名义基线的 1,000 行混淆矩阵（行是真值 0–3，列是预测 0–3）为 `[[244,0,5,1],[1,241,4,4],[6,5,227,12],[1,5,7,237]]`，各类召回率为 97.6%、96.4%、90.8%、94.8%；该矩阵来自复用的开发验证子集。

因此，P2 的表现依赖当前假设的横向工艺算子；测试的高度噪声种子范围影响较小，但 PSF、最小特征和组合偏差可能大幅损害分类。64 级高度量化在本轮保持固定，**没有测量量化级别敏感性**。P1 则呈现另一取舍：未加工选定相位在开发验证上 Accuracy 96.25%，经名义加工后只剩 37.9%，尽管效率升至 33.35%。旧的 P3 数字不能用于替代这次修正结果。

孔径场景使用各候选的源相位，单独作为光学孔径扫描解读；它不属于上表的“其余名义加工项固定”的工艺单因素结论。原始 JSON 中字段名 `flip_rate_from_ideal` 沿用了旧名称；修正后的数值实际以名义加工基线计算，已由保存的预测重新核对。

这些结论只支持“在本次数值几何和假设工艺算子下，单层高度候选可以产生高四 ROI 分类分数，并对特定横向工艺参数敏感”。它们不证明实物 LightGen 器件能做到相同复透射，也不证明光学图像生成能力。

## 目标缺口

- 无独立 MNIST 评估人口。官方测试集图像没有读取；但标签人口审计显示 C0 已覆盖所有 0–3 测试索引，故不能从现有样本再声称独立测试表现。
- 无材料在 532 nm 的折射率/吸收与复透射测量，P5 的 Δn=0.5/0.6、单位振幅均为假设。
- 无打印机横向 PSF、最小可用特征、量化级别、高度噪声和边缘效应实测；没有依据把 σ=0.8 px 等值写成设备性能。
- 当前 P3 把量化固定为 64 级，边缘偏差只出现在组合不利情景；尚无独立量化级别或边缘偏差单因素敏感性结果。
- 200×200 µm STL 未完成通用自交检测或实际切片/打印验证，不能放行制造。
- HW207 的 DMD ON/OFF 收光、输入和输出共轭/倍率、LightGen 位置与方向、CMOS 实物身份及四 ROI 坐标仍未闭环。
- 无 DMD→实物器件→CMOS 的端到端记录；四分类结果不等同于光学生成质量、语义正确性或人眼可读性。

## 决策影响与下一步

C3.5 可作为**假设工艺条件下的数值候选筛选**收尾；总体状态保留 `C3.5_PARTIAL_PASS`，P4、P5、`C3.5_FABRICATION_READY` 和 `HW207_CURRENT_MAPPING` 不改写为通过。C3.4 的固定 C3.3 相位不能直接支撑 Model B；几何/加工感知优化能在复用开发数据上恢复 ROI 分类，但尚无同一独立样本配对证据、真实制造参数或实物光路映射。

建议下一步先取得材料 Δn/吸收、打印机横向与高度响应、Relay/CMOS 实测坐标及 ROI 标定，再决定是否设计一轮独立验证。以上是建议；本报告不授权新训练、打印、器件采用、DMD/CMOS 操作或硬件实验，也不自动启动 C3.6。
