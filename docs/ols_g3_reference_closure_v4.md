# Gaussian/OLS 独立参考闭合与 G3 复核 v4

## 结果与状态

AutoDL 完整任务以退出码 0 结束，独立参考有效，整体状态为 `VALID_FAILED / G3_FAIL`。本轮保留原 532 nm、2 μm 采样、两层 100×100 相位屏、两段 1.5 mm 传播、每层功率透射 0.889、249.3 μW 输入、125 μm pitch、假设 MFD 14.222 μm、2048/3072/4096 三个计算窗口、共同 4.096 mm ROI 和原 `1e-4` G3 门槛。

CPU complex128 非周期带限角谱参考在 25 个固定 ROI 点、100 个fiber最近像素点和合并 125 点上通过收敛要求。GL4 每轴节点依次为 2048、4096、8192、16384、32768；判据为相对 L2 差及最大点差除以固定场尺度 `E0=78.9461842016446` 均不超过 `1e-7`。所有相位与点组的两个末级区间均通过：8192→16384 的最坏相对 L2 差 `1.7186513268e-9`、最坏点差/E0 `8.9764151450e-10`；16384→32768 分别为 `4.8464567070e-12` 和 `2.5024729929e-12`。32768 节点下 GL8/GL4 交叉阶数复核的最坏相对 L2 差为 `3.9264574460e-14`，最坏点差/E0 为 `1.7490829297e-14`。这些值均小于原定 `1e-7`，未扩大空间网格或放宽门槛。

生产 G3 仍消费完整两段生产路径的 9 项共同 ROI 比较，结果没有改变：complex64 最大 raw 复场相对误差 `1.6014414535e-4`，共同全局相位对齐后 `1.6014370095e-4`；complex128 对齐后 `1.6014355370e-4`。最大项仍是末层 x/y 各 1°、2048 对 4096。G3 门槛保持 `1e-4`，因此有效测量未通过。raw 复场、对齐复场、强度、ROI功率与全局相位指标重算后，与 v3 原报告的最大差异为 `1.0873537755e-7`，CPU 重读的 Gate 决策与原 v3 一致。

## 科学认识

v3 的独立参考无效问题已经解决：逐级积分复数值被保存并从回传的原始 `.npz` 重新读取；两段末级 GL4 细化和独立 GL8 复核对本计划定义的 125 个位置收敛。该参考验证的是指定离散输入场在 Nyquist 频率方形域内的非周期带限积分模型：\[\widehat E(f)=\Delta A\sum_p E_p e^{-i2\pi f\cdot r_p},\qquad E_{ref}(r)=\int_{[-1/(2dx),1/(2dx)]^2}\widehat E(f)H(f)e^{i2\pi f\cdot r}d^2f.\] CPU使用complex128、复合4点Gauss–Legendre逐级积分，并在32768节点用8点阶数交叉复核；逐级复场值、节点/权重、输入和坐标保存在原始`.npz`归档。该模型不是实物连续光阑测量，也未加入像素sinc、额外滤波或相位拟合。输入来自明确的v3运行目录`outputs/20261014_ols_g3_second_hop_error_isolation_v3/runs/attempt_01`，未使用`latest`。

固定采样点上，生产与参考的复场差随计算窗口变大而减小；但 G3 的完整 ROI complex64 误差依旧超过门槛，且 complex128 结果几乎相同。因而本轮能确认的是：参考收敛后，原 G3 失败依旧存在；不能把少量点的趋势外推为全 ROI 误差归因。周期边界与 FFT 频率采样的贡献仍未独立区分。本轮未证实新的生产实现缺陷，也未证明 Gaussian 模型或 10×10 物理结构不可行。

## 目标缺口

G3 是后续 OLS 响应谱、绝对功率和维度决策的先决检查，当前仍未通过。尚缺能够解释完整共同 ROI 窗口差异的证据；本轮没有生成 K/H 响应矩阵、奇异谱或维度排序，也没有复核 Decoder/camera 接口。Fiber 几何、MFD和相机标定仍是未测量的仿真假设。旧生成训练的checkpoint恢复验收是独立待办，历史工程更新计数仍为 39/45。

## 工程完成与验证

完整任务在 AutoDL `autodl-monthly`、`/root/miniconda3/bin/python` 上运行；环境为 Python 3.12.3、PyTorch 2.5.1+cu124、CUDA 12.4、RTX 4080。完整任务观察耗时 1557.123 秒；遥测 26 条，采集失败 0。频率行分块 64、位置批量 16。云端预检覆盖生产解析平面波、非周期积分 sinc/相干叠加、遗漏面积/复相位/半像素坐标负例，以及第二段独立调用；负例均按预期被拒绝。回传后在本地重新读取 18 份积分归档并重算全部 125 点及逐级收敛，结果通过；完整报告中 CPU 重读与原报告判定一致。

预检复核还发现一个报告字段问题：原始完整报告及原始`preflight.json`中，双像素复相位负控的细节布尔值为`false`，而同一预检的聚合负控判定为通过。两份原始文件保持原样，保存在[完整回传证据目录](../outputs/20261014_ols_g3_reference_closure_v4/runs/autodl_backup_attempt_01)；研究专用检查改为消费独立丢相位误差阈值，并添加对应回归用例。修正后的云端预检显示`lost_phase_rejected=true`，聚焦测试`8 passed`，Python编译退出码 0；本地 Ruff 与编译通过。该工程修正不改变传播公式、生产路径或 G3 结果。

完整运行精确回传 66 个文件、3,854,400 字节；修正预检精确回传 13 个文件、257,514 字节，逐项大小核对完成。临时覆盖的 4 个既有云端源码逐字节恢复，9 个原本不存在的临时文件按路径清理；两份 restoration receipt 均为 `RESTORED_AND_VERIFIED`。完整原始云端报告、原始失败尝试、修正预检及失败重试日志都保存在 [完整回传证据目录](../outputs/20261014_ols_g3_reference_closure_v4/runs/autodl_backup_attempt_01) 与 [预检复核回传目录](../outputs/20261014_ols_g3_reference_closure_v4/runs/autodl_backup_preflight_rechecks)。[回传后本地重读审计](../outputs/20261014_ols_g3_reference_closure_v4/runs/attempt_01/post_return_audit.json) 为 `LOCAL_RETURNED_EVIDENCE_READBACK_PASS`。

完整运行日志还保留了一条 PyTorch 提示：构造基线 LP01 runtime 时，`nn.Module.to(dtype=real_dtype)` 将复数注册缓冲区转为实数。固定本轮配置的 LP01 模态由实值径向剖面构成、transport 为恒等矩阵，两者虚部均为零；这条提示不涉及自由空间 G3 场传播，也没有显示本轮读出差异。但非恒等复数 transport 或具有非零复相位的模式不能沿用这种 dtype 转换；应在后续引入前独立修复/验证。本轮未修改该共享前向路径。

本轮训练更新、相位优化、数据集读取、任务评价器/FID、loss修改、材料前向、求解器替换和光路几何改动均为 0。

## 决策影响与下一步

有效的独立参考消除了“参考积分本身未收敛”这一工程不确定性，但没有使生产 G3 通过。当前应继续把维度矩阵、维度排序和结构选择挡在 G3 之后；下一步可另行设计一次只针对全 ROI 误差来源的受控诊断，沿用原三窗口、生产 complex64 路径和 `1e-4` 门槛。若后续仍失败，应保留 G3 FAIL 并报告机制边界；不得以 125 点、complex128、功率稳定或独立参考局部一致替代 Gate，也不得更换求解器制造通过。

建议顺序仍为：G3闭合 → OLS响应谱与绝对功率 → 有限相位优化并保存相位 → Decoder/camera接口 → 非线性敏感性 → 单独规划生成训练。本报告只给出建议，不授权这些后续工作。Gaussian S12 主参考、LP01 模式敏感性对照及旧checkpoint不自动迁移或重定标；旧生成恢复待办仍保持独立。
