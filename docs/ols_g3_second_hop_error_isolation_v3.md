# Gaussian/OLS 第二段传播误差定位 v3

AutoDL完整测量退出码为0，科学状态为 **`VALID_FAILED / G3_FAIL`**。G3继续消费原三种固定相位、4.096/6.144/8.192 mm窗口、共同4.096 mm ROI上的9组生产complex64比较，门槛保持`1e-4`。最坏项是末层x/y各1°、2048对4096窗口。

| 指标 | 生产complex64 | complex128诊断 |
|---|---:|---:|
| 最大raw复场相对误差 | 1.60144145e-4 | 1.60144027e-4 |
| 最大共同全局相位对齐复场误差 | 1.601436996e-4 | 1.601435537e-4 |
| 最坏项共同全局相位 | 3.77235e-7 rad | 3.89182e-7 rad |
| 最大强度相对误差 | 3.68069e-5 | 3.68016e-5 |

## 科学认识

共同入口的分层测量把误差定位到第二段窗口相关传播，而不是仅由第一段造成：第一段共同ROI最大对齐误差为`7.7903e-6`；200 μm光阑内100×100复场裁切最大对齐误差为`2.0140e-7`。固定同一个4096窗口complex128第二段入口、只转换一次complex64后，第二段跨窗口最大对齐误差仍为complex64 `1.6014450e-4`、complex128 `1.6014368e-4`。因此第一段窗口差异不能解释全部G3残差。

当前传播核与CPU NumPy高精度生成核比较，在三个网格上的相对差均为0；把同一complex64核用于两种FFT累积精度时，场差为`4.19e-7`至`4.34e-7`。这与complex64/complex128最终残差几乎相等共同说明：本轮没有证据支持浮点累积是主因。旧float32相位核作为负例仍产生约`6.75e-4`差异，记录其已由此前修复处理，不将其误报为本轮新修复。

最坏误差图中，中心200 μm方形区域约占总误差能量的2.57%，包含光纤阵列的1.25 mm方形区域约占18.55%，其外的共同ROI约占81.45%。后两个区域的定义分别是阵列整体方形与其补集；中心方形位于阵列方形内，二者不应相加。误差主要出现在fiber-array外的ROI，但该区域统计只定位误差，不改变整幅ROI的G3判定。

坐标裁切按三个窗口的物理坐标执行，ROI索引分别为`[0,2048)`、`[512,2560)`、`[1024,3072)`。首像素中心的最大浮点坐标差为`4.34e-19 m`，属于双精度舍入量级；报告中的严格布尔坐标相等标记为false，不能据此称物理裁切不一致。

CPU独立参考按照固定dx的非周期带限角谱积分和复合四点Gauss–Legendre积分执行，频率节点数为512、1024、2048、4096。最终两级的25个ROI采样点没有收敛：三种相位的相对L2差约`9.05e-3`至`1.09e-2`，最大点差/E0约`5.09e-3`至`5.41e-3`，远高于`1e-7`。100个fiber最近像素点中，零相位通过该收敛门槛，但x坡度和xy坡度仍未通过。因此独立参考整体状态为`INVALID_NONCONVERGED_REFERENCE`，不能用它区分FFT频率采样、周期边界交互或其他第二段窗口机制；也不把它与同一离散算子的CPU NumPy复算混为独立物理收敛证据。

固定第二段输入、4096窗口complex128下，Gaussian S12与同几何LP01的逐通道复系数和功率均保存于机器报告。示例总fiber耦合如下（每行均为同一输入复场、末层相位、4096窗口）：

| 末层相位 | 模式 | 总耦合功率 | 端面耦合效率 | 输入至fiber系统效率 |
|---|---|---:|---:|---:|
| 零相位 | Gaussian S12 | 9.35110 μW | 5.06355% | 3.75094% |
| 零相位 | LP01 | 11.95107 μW | 6.47142% | 4.79385% |
| x方向1° | Gaussian S12 | 2.43622 μW | 1.31920% | 0.97723% |

两种模场仍是模式敏感性对照，不要求耦合数值相等，也不据此改变Gaussian主参考的选择。G3比较中的逐fiber latent采用单个共同全局相位，不做逐fiber相位对齐。跨窗口最大latent共同相位对齐误差分别为Gaussian/LP01包含在机器报告的完整数组中；对全部相位和窗口对汇总，complex64 latent最大对齐误差为`2.0662e-7`、逐通道功率相对L2误差最大`3.7249e-7`；complex128对应`7.0677e-8`和`6.4000e-8`。这些fiber读数稳定不替代整幅复场G3失败。

## 目标缺口

本轮没有找到新的坐标、面积、复相位、核精度或第二段调用实现缺陷可用于最小修复。误差在固定第二段入口后保留，支持“第二段窗口依赖”这一局部结论；独立CPU参考未收敛，使误差机制归因仍未闭合。G3仍失败，故本轮不支持继续OLS响应矩阵/维度排序；也没有证明Gaussian或整个光学架构不可用。光纤pitch、MFD和器件参数依旧是未测量的仿真假设。

## 决策影响与下一步

本轮只确认了第二段传播在固定共同入口下仍有超门槛的窗口差异，没有证明是哪种有限窗口机制，也没有找到可修复的生产代码缺陷。原G3保持`FAIL`，不得用功率稳定、fiber latent小误差、complex128读数或CPU同离散核复算替代。

建议下一项工作先单独解决独立参考在既定ROI采样点上的收敛性，并维持现有物理几何、窗口和`1e-4` G3门槛；参考有效后再判断第二段误差机制。只有生产G3通过且参考有效，才另行规划OLS响应谱/功率复核。以上是建议，不是本轮授权。正式训练、通道维度决策、材料非线性、decoder/camera接口接入及生成任务均未启动。
