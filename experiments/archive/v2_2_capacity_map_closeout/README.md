# v2.2 conditional-negative closeout

This is a read-only evidence capsule for the diagnostic-only capacity-map
branch. It records a closed result, not a runnable experiment and not a formal
promotion candidate.

The sole permitted conclusion is that the declared E2:O0 teacher-free
objective family did not pass the qualified dual-evaluator gate. The capsule
does not support an optical, phase-only, spatial-DOF, or universal
semantic-diversity conclusion.

`archive_index.json` binds each copied file to its source path, byte count, and
SHA-256. Evidence JSON files are byte-for-byte copies so their embedded
`content_hash` fields remain valid. Checkpoints, datasets, caches, images, and
training logs are deliberately excluded; their original references remain in
the immutable evidence JSON.
